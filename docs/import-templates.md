# 数据导入表格格式规范

本文档定义教师端"数据导入"功能各类表格的格式要求，用于制作导入数据（含测试数据）。
所有格式与后端解析逻辑、`GET /api/import/template/{importType}` 下载的官方模板保持一致。

## 通用说明

- 支持 `.xlsx` / `.xls` / `.csv` 三种格式，单文件不超过 10MB。
- **第一行必须为表头**，列名需与本文档完全一致（前后空格会被忽略）。
- **课程归属**：在导入页面选择课程后上传（前端自动传 `courseId`）。直接调 API 时也可省略 `courseId`，
  改用文件名约定 `{课程编号}_{类型}_{名称}.xlsx`（如 `CS-NET-001_HOMEWORK_第1次作业.xlsx`）由系统解析课程。
  两者均无法确定课程时导入返回 `FAILED`。
- **推荐导入顺序**：① 学生名单（选课导入）→ ② 成绩 / 考勤 / 实验。
  成绩、考勤、实验导入要求学生已存在于系统（按学号匹配），学生不存在的行会计入失败。
- 重复数据（已存在的学号 / 同考核同学生的成绩 / 同日考勤）自动跳过，计入"跳过"并在结果中提示，不会覆盖已有数据。
- 每 500 行一批独立提交：部分行失败不影响其他行，失败原因（含行号）在导入结果中逐条列出。

## 1. 学生名单（选课导入，CLASS_STUDENT）

**用途**：导入某门课程的选课学生名单。学号不存在的学生自动创建登录账号（初始密码为系统默认配置，
用户名 = 学号），并加入所选课程；已存在的学生直接加入课程（并更新班级信息）。
"班级"列填**行政班级**（如"软件2201"），课程归属由页面选择的课程决定。

**前置条件**：页面选择课程。

| 列名 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 学号 | ✅ | 唯一标识，作为登录用户名 | S2024001 |
| 姓名 | ✅ | | 赵小明 |
| 性别 | ❌ | 男 / 女 | 男 |
| 学院 | ❌ | | 计算机学院 |
| 专业 | ❌ | | 软件工程 |
| 班级 | ❌ | 行政班级 | 软件2201 |
| 年级 | ❌ | | 2022 |
| 邮箱 | ❌ | | zhao@example.com |

**示例行**：`S2024001 | 赵小明 | 男 | 计算机学院 | 软件工程 | 软件2201 | 2022 | zhao@example.com`

## 2. 作业 / 测验 / 期中期末成绩（HOMEWORK / QUIZ / EXAM_SCORE）

**用途**：导入一次考核的学生成绩，含逐题得分与扣分知识点（用于知识点掌握度分析）。
三种类型共用同一表格格式。

**前置条件**：页面选择课程 + 填写考核名称（期中/期末还需选择考试类型）；学生已导入。

**列定位规则**：按**表头列名**定位，列顺序可调整；题目数量由表头中"第N题得分"列的个数自动检测，
支持任意题数（每题一列得分 + 紧随其后一列扣分知识点）。无题目列时仅导入总成绩。

| 列名 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 序号 | ❌ | 行序号 | 1 |
| 学号 | ✅ | 须已存在于系统 | S2024001 |
| 姓名 | ❌ | 仅展示用，以学号为准 | 赵小明 |
| 第1题得分 | ❌ | 数字，每题满分按 20 分计 | 18 |
| 扣分主要知识点 | ❌ | 紧跟在对应题目得分列右侧；多个知识点用逗号/顿号/斜杠分隔 | 线性表,栈 |
| 第2题得分 … 第N题得分 | ❌ | 同上，成对出现 | 20 |
| 总成绩 | ✅ | 数字；缺省该列时按各题得分求和 | 90 |
| 最薄弱知识点 | ❌ | | 线性表 |

**表头示例**（5 题）：

```
序号 | 学号 | 姓名 | 第1题得分 | 扣分主要知识点 | 第2题得分 | 扣分主要知识点 | ... | 第5题得分 | 扣分主要知识点 | 总成绩 | 最薄弱知识点
```

**示例行**：`1 | S2024001 | 赵小明 | 18 | 线性表 | 20 |  | 15 | 二叉树 | 20 |  | 19 | 图 | 92 | 二叉树`

**去重规则**：同一考核（课程 + 考核名称 + 考核类型）下同一学生只保留首次导入的成绩，重复行跳过。

**文件名约定（API 直调回退）**：`{课程编号}_HOMEWORK_{考核名称}.xlsx`、`{课程编号}_QUIZ_{考核名称}.xlsx`、
`{课程编号}_EXAM_SCORE_MIDTERM_{考核名称}.xlsx`（期中）、`{课程编号}_EXAM_SCORE_FINAL_{考核名称}.xlsx`（期末）。

## 3. 考勤记录（ATTENDANCE）

**前置条件**：页面选择课程；学生已导入。

| 列名 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 学号 | ✅ | 须已存在于系统 | S2024001 |
| 姓名 | ❌ | 仅展示用 | 赵小明 |
| 日期 | ✅ | 格式 `yyyy-MM-dd`，格式错误计入失败 | 2025-09-08 |
| 状态 | ✅ | 出勤 / 迟到 / 早退 / 缺勤 / 请假 | 出勤 |
| 节次 | ❌ | | 1-2节 |
| 第几周 | ❌ | 数字 | 3 |
| 备注 | ❌ | | |

**去重规则**：同课程 + 同学生 + 同日期 只保留一条，重复行跳过。

## 4. 实验报告（EXPERIMENT）

**前置条件**：页面选择课程；学生已导入。

| 列名 | 必填 | 说明 | 示例 |
|------|------|------|------|
| 学号 | ✅ | 须已存在于系统 | S2024001 |
| 姓名 | ❌ | 仅展示用 | 赵小明 |
| 实验名称 | ✅ | | 实验一：网络抓包 |
| 实验次数 | ❌ | 数字 | 1 |
| 分数 | ❌ | 数字，非数字计入失败 | 85 |
| 提交时间 | ❌ | 格式 `yyyy-MM-dd HH:mm:ss`，格式错误计入失败 | 2025-09-15 20:30:00 |
| 备注 | ❌ | | 按时提交 |

## 5. 管理端基础数据导入（教师 / 学生 / 课程）

以下类型不需要课程归属，供管理员批量初始化基础数据使用：

| importType | 表头列 | 唯一键（重复跳过） |
|------------|--------|-------------------|
| `TEACHER` | 工号、姓名、性别、学院、系/部门、职称、邮箱、联系电话 | 工号 |
| `STUDENT` | 学号、姓名、性别、学院、专业、班级、年级、邮箱 | 学号 |
| `COURSE` | 课程编号、课程名称、授课教师工号、学分、课程类型、学期、课程描述 | 课程编号 |

- `TEACHER` / `STUDENT`：新记录自动创建登录账号（用户名 = 工号/学号，初始密码为系统默认配置）。
- `COURSE`：授课教师工号必须已存在，否则该行计入失败；学期格式 `YYYY-YYYY-N`（如 `2025-2026-1`）。
- `KNOWLEDGE_POINT`：仅提供模板，导入功能暂未开放。

## 常见错误对照

| 导入结果提示 | 原因 | 处理方式 |
|-------------|------|---------|
| 无法确定归属课程 | 未选课程且文件名不含有效课程编号 | 页面选择课程后重新上传 |
| 无法确定考核名称 | 成绩导入未填考核名称且文件名不符合约定 | 页面填写考核名称 |
| 学生不存在: Sxxx | 学号未导入系统 | 先通过"学生名单"导入该学生 |
| 日期格式错误 | 考勤日期不是 `yyyy-MM-dd` | Excel 中将该列设为文本并按格式填写 |
| 表头缺少"学号"列 | 表头列名与模板不一致 | 下载官方模板重新填写 |
| 未解析到任何数据行 | 文件只有表头 / 表头行不在第一行 | 检查数据从第二行开始且表头在首行 |
| 学号已存在，跳过 | 重复导入 | 属正常去重，无需处理 |
| 在该考核已有成绩记录，跳过 | 同一考核重复导入同一学生 | 如需覆盖请先删除原考核记录 |
