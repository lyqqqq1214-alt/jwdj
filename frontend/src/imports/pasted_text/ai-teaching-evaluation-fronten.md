# AI教学评价系统 - 前端需求文档（V1.0）

## 一、系统概述

### 1.1 系统定位
一款面向高校的AI教学评价与个性化学习系统，核心价值是**通过AI分析为学生提供每门课程的学期学情画像、个性化建议和针对性练习**。

### 1.2 角色矩阵
| 角色 | 简称 | 核心目标 |
|------|------|----------|
| 管理员 | Admin | 系统总控、用户管理、数据配置 |
| 教师 | Teacher | 管理课程、上传数据、查看班级学情 |
| 学生 | Student | 查看个人学情报告、获取建议、进行针对性练习 |

### 1.3 通用交互规范
- **登录方式**：统一登录入口，角色选择后跳转不同首页
- **导航**：左侧边栏菜单 + 顶部面包屑
- **响应式**：PC端优先（最低支持1366×768），兼容平板
- **主题**：支持浅色/深色模式切换
- **反馈**：所有操作需有Loading状态和成功/失败Toast提示


## 二、登录与权限模块

### 2.1 登录页
**路径**：`/login`

**页面元素**：
| 元素 | 类型 | 说明 |
|------|------|------|
| 学校Logo | 图片 | 左上角，可配置 |
| 系统名称 | 文本 | “AI教学评价系统” |
| 账号输入框 | Input | 文本输入，placeholder="请输入学号/工号" |
| 密码输入框 | Input | 密码类型，带显示/隐藏切换 |
| 角色选择 | Tab切换 | 三个Tab：管理员｜教师｜学生，默认选中学生 |
| 登录按钮 | Button | 主按钮，点击后校验身份 |
| 记住账号 | Checkbox | 默认未勾选 |

**交互流程**：
1. 用户输入账号密码 → 选择角色 → 点击登录
2. 前端校验：账号非空、密码长度≥6
3. 调用登录接口 → 成功后存储Token和角色信息 → 跳转对应首页
4. 失败时在密码框下方显示红色错误提示

**接口需求**：
```
POST /api/auth/login
Request: { username, password, role }
Response: { code, message, data: { token, userId, name, role, avatar } }
```

### 2.2 权限拦截
- 未登录用户访问任何页面 → 重定向到 `/login`
- 已登录用户访问非本角色页面 → 跳转403页面

### 5.2 学情报告页（核心）
**路径**：`/student/report/:courseId`

**页面结构**：自上而下展示以下模块

---

#### 模块1：课程概览
| 数据项 | 说明 |
|--------|------|
| 课程名称 + 授课教师 | 顶部标题区 |
| 总评成绩 | 大号数字突出显示 |
| 平时成绩 / 期末成绩 | 并排显示 |
| 班级排名 | 如 "15/48" |
| 成绩等级 | 优秀(≥90)｜良好(80-89)｜中等(70-79)｜及格(60-69)｜不及格(<60) |

---

#### 模块2：成绩趋势
- **折线图**：显示本学期历次测验/作业的成绩变化
- X轴：时间（第1次测验、期中、第2次测验...）
- Y轴：分数（0-100）

---

#### 模块3：知识点掌握度（核心AI分析结果）
**可视化方式**：雷达图 或 条形图

**展示形式**（以高数为例）：
```
微积分      ████████████████░░░░  82%
线性代数    ██████████████░░░░░░  74%
概率统计    ████████████░░░░░░░░  65%
微分方程    ██████░░░░░░░░░░░░░░  38%  ← 薄弱（红色标识）
```

- **薄弱知识点**用红色高亮，并显示具体掌握度百分比
- 点击任意知识点可查看：该知识点的详细说明、涉及到的考试题目

---

#### 模块4：AI个性化学习建议
**展示形式**：卡片列表，每条建议包含：

| 字段 | 示例 |
|------|------|
| 建议标题 | “加强微分方程的理解与应用” |
| 建议详情 | “你在常微分方程的求解上失分较多，建议先复习课件第4.2-4.4节，重点理解一阶线性微分方程的解法。” |
| 关联知识点 | “微分方程” |
| 建议操作按钮 | 「开始针对性练习」 |

- 建议按优先级排序（最薄弱的知识点排最前）

---

#### 模块5：针对性练习
**功能**：根据薄弱知识点，AI自动生成测试题

**页面交互**：
1. 在薄弱知识点卡片中点击「开始针对性练习」
2. 进入练习模式：
   - 显示题目（选择题/判断题/填空题）
   - 每题作答后立即显示正确/错误和解析
   - 进度条显示完成进度
   - 练习完成后显示得分和错题回顾

**出题逻辑**（前端需支持）：
- 调用接口 `POST /api/quiz/generate`，传入课程ID和知识点列表
- 返回题目列表（包含题目、选项、答案、解析）
- 前端仅作展示和交互，不参与出题逻辑

---

#### 模块6：课程资源
- 展示教师上传的课件列表（PDF/PPT图标，支持在线预览或下载）
- 按章节/时间排序

## 八、与后端的接口约定（建议）

### 8.1 统一响应格式
```typescript
interface ApiResponse<T> {
  code: number;        // 0表示成功，非0表示失败
  message: string;     // 提示信息
  data: T;
}
```

### 8.2 关键接口清单（前端需要调用的）

| 模块 | 接口 | Method | 说明 |
|------|------|--------|------|
| 认证 | `/api/auth/login` | POST | 登录 |
| 认证 | `/api/auth/logout` | POST | 登出 |
| 认证 | `/api/auth/info` | GET | 获取当前用户信息 |
| 管理员 | `/api/admin/users` | GET/POST/PUT/DELETE | 用户CRUD |
| 管理员 | `/api/admin/courses` | GET/POST/PUT/DELETE | 课程CRUD |
| 管理员 | `/api/admin/config` | GET/PUT | 系统配置 |
| 教师 | `/api/teacher/courses` | GET | 获取所授课程列表 |
| 教师 | `/api/teacher/course/:id/students` | GET | 获取课程学生列表 |
| 教师 | `/api/teacher/course/:id/data` | POST | 上传成绩/考勤 |
| 教师 | `/api/teacher/course/:id/resources` | GET/POST/DELETE | 课件资源管理 |
